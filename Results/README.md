# Results

This folder contains outputs generated during the DHCR7 phylogenetic analysis.

Files:

- Blast_dm_vs_atl.tsv : BLAST results between DM and Atlantic CDS sequences
- atlantic_ids.txt : Unique Atlantic homolog IDs extracted from BLAST output
- combined_alignment.fa : Combined sequence alignment generated using MAFFT
- combined_aln.fa.treefile : Maximum Likelihood phylogenetic tree generated using IQ-TREE2
- phylogenetic_tree.png : Annotated phylogenetic tree visualized using iTOL
